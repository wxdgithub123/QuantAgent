QuantAgent PRD 10.1-10.3 完成验收报告

更新时间：2026-05-27 | 分支：yhy | 工作副本：QuantAgent-master-work/quantagent/QuantAgent-main

一、完成结论

本次按需求文档完成 PRD 10.1 数据接入、10.2 标准化与存储、10.3 因子与信号的代码闭环。系统现在具备 crypto / 股票 / 新闻 / 宏观统一接入，OpenBB provider 切换与降级，平台标准对象与版本/三时间语义字段，PostgreSQL + DuckDB + Parquet 分层存储，以及技术指标、新闻情绪、事件标签、宏观因子、信号触发和 AnalysisContext 组装能力。

外部数据源
  -> OpenBB 统一接入 + 自定义备用源
  -> 标准化对象(BarData / NewsEvent / MacroEvent / FactorSnapshot / SignalEvent)
  -> PostgreSQL + DuckDB + Parquet
  -> 技术因子 + 新闻情绪/事件标签 + 宏观因子
  -> SignalEvent + AnalysisContext
  -> L6 TradingAgents / CoordinatorAgent 消费入口

八、质量复查修复项

  • 已修复：DuckDB 不支持 XXHASH64(url) 默认主键，改为 Python 侧稳定哈希生成 id，并完成实写验证。
  • 已修复：PostgreSQL 因子/信号表字符串字段偏短，已放宽 factor_name、strategy_id、provider、schema_version 等字段并同步迁移。
  • 已修复：L5 窗口替换逻辑的缩进可读性问题，避免后续维护误判。
  • 已修复：OpenBB crypto ticker 调用由位置参数改为 keyword 参数，减少 SDK 版本差异导致的失败。
  • 已修复：宏观数据拉取固定使用 FRED provider，避免被行情默认 provider 误传。
