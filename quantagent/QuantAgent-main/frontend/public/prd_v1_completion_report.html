3. 主流程链路

PRD 的主线是“外部数据源 → OpenBB → 标准化 → 存储 → 因子信号 → AnalysisContext → TradingAgents → 审计/回测”。当前实现如下：

L1 数据源

OpenBB/yfinance、FRED/OECD、CCXT、新闻源、股票样例。

L2 统一接入

MarketDataGateway 与 OpenBBDataService 做 provider fallback。

L3 标准化

Instrument、Bar、NewsEvent、MacroEvent 保留时间与版本字段。

L4 存储

ClickHouse 主时序库，PostgreSQL 主状态，DuckDB/Parquet 分析归档。

L5 因子信号

33 个因子定义，28,494 条快照，13,502 条信号事件。

L6 TradingAgents

消费 AnalysisContext 输出结构化建议，写入 coordination_history。

L7 回测审计

回测、回放、审计台、决策追踪和结果对比接口。

4. 数据来源与真实含义

为了避免误解，下面把当前页面看到的数据来源讲清楚。这里区分“库支持”“项目实际使用”“前端实际展示”。

Crypto K线

主链路是 OpenBB/yfinance 拉取后写入 ClickHouse。前端 K 线和回测主要读取 ClickHouse 缓存；ClickHouse 不是真正来源，而是本地时序缓存。

真实上游：OpenBB/yfinance；补充：CCXT/OKX
CCXT

CCXT 是交易所连接库，当前健康检查显示库可注册 7 个交易所连接器。但为了避免误导，前端交易所选择只暴露当前实际使用的 OKX。

用途：实时交易所报价、未来执行接口补充
新闻

新闻接口当前从 DuckDB 读取结构化新闻记录，来源链路主要是 OpenBB/yfinance 新闻。原版 TradingAgentsGraph 实验入口会使用自己的 Google News RSS，不属于主链路。

当前 BTC 新闻：15 条
宏观数据

宏观指标通过 OpenBB 的 FRED/OECD 链路进入 DuckDB，并保留 provider、schema_version、available_time。

FEDFUNDS、DGS10、T10YIE、M2SL、CPI、失业率
