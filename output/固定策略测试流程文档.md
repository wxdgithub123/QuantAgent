## —— B 同学分工：固定策略回测实验

## 一、实验目标

测试四种固定技术指标策略在加密货币市场上的表现，作为后续 Agent 策略切换方案的 **baseline 对照组**。

核心问题：**单一固定策略能否在不同市场环境下持续盈利？**

## 三、策略设计

### 3.1 策略候选池

| 策略 | 类型 | 做多信号 | 做空信号 |
|------|------|----------|----------|
| **Bollinger Bands** | 均值回归 | BBP < 阈值 | BBP > 阈值 |
| **MA Cross** (双均线) | 趋势跟随 | 快线金叉慢线 | 快线死叉慢线 |
| **RSI** | 超买超卖反转 | RSI < 超卖线 | RSI > 超买线 |
| **MACD** | 趋势动量 | MACD 金叉信号线 | MACD 死叉信号线 |

### 3.2 策略信号公式

#### Bollinger Bands
```
BBP = (Close - Lower) / (Upper - Lower)
Signal =  1  (LONG)  当 BBP < bb_long_threshold
Signal = -1  (SHORT) 当 BBP > bb_short_threshold
```

#### MA Cross (双均线)
```
Signal =  1  (LONG)  当 MA_fast 从下方上穿 MA_slow
Signal = -1  (SHORT) 当 MA_fast 从上方下穿 MA_slow
```

#### RSI
```
Signal =  1  (LONG)  当 RSI < oversold
Signal = -1  (SHORT) 当 RSI > overbought
```

#### MACD
```
Signal =  1  (LONG)  当 MACD 线从下方上穿 Signal 线
Signal = -1  (SHORT) 当 MACD 线从上方下穿 Signal 线
```

## 四、回测引擎设计

### 4.1 整体架构

```
CSV 数据加载 → 指标计算 → 信号生成 → 逐笔模拟 → 指标汇总
                                    ↑
                              Triple Barrier 出场
                           (止盈 / 止损 / 时间止)
```

### 4.2 入场规则

- 信号产生后，在 **下一根 K 线的开盘价** 入场
- 信号方向：1 = 做多 (LONG)，-1 = 做空 (SHORT)
- 持仓期间不产生新信号（避免重叠持仓）
- 出场后立即从下一根 K 线开始继续扫描信号

### 4.3 出场规则（Triple Barrier）

| 出场类型 | 说明 |
|----------|------|
| **止盈 (TP)** | 价格触及 `entry_price × (1 ± tp)` |
| **止损 (SL)** | 价格触及 `entry_price × (1 ∓ sl)` |
| **时间止 (TL)** | 持仓达 `time_limit` 小时，以最后 K 线收盘价出场 |

### 4.4 同 K 线内 TP/SL 同时触发处理

当一根 K 线同时穿越 TP 和 SL 时，使用**价格动线比例法**判定先触及的价位：

- **做多**: `(Open - Low) / (High - Low)` > 0.5 → SL 先触及，否则 TP 先触及
- **做空**: `(High - Open) / (High - Low)` > 0.5 → SL 先触及，否则 TP 先触及

### 4.5 交易成本

- 单边手续费 + 滑点合计: **0.03%**（双边 0.06%）
- 基于现货交易假设

## 五、实验流程

### Step 1: 网格搜索（参数搜索集）

在 18 个月的参数搜索数据上，对每个策略的每种参数组合运行回测，记录训练指标。

**单次回测流程**:
1. 在完整搜索数据集上计算技术指标
2. 根据参数生成交易信号
3. 逐 K 线扫描入场（信号 + 冷却检查）
4. Triple Barrier 出场判定
5. 计算收益率、Sharpe、最大回撤等指标

### Step 2: 验证集筛选

对网格搜索中表现靠前的参数组合，在 5 个月验证数据上评估，按**验证集 Sharpe 比率**排序。

> 使用验证集而非训练集进行参数排序，可减少过拟合到单一市场环境的偏差。

### Step 3: 测试集评估

取验证集表现最优的 **Top-3** 参数组合，在 6 个月测试数据上进行最终评估。选择测试集 Sharpe 最高的参数作为该策略的最终结果。

### Step 4: 汇总输出

汇总所有策略的最终测试指标，包含：
- **累计收益率 (Total Return)**
- **最大回撤 (Max Drawdown)**
- **Sharpe 比率**
- **胜率 (Win Rate)**
- **总交易次数**
- **盈亏比 (Profit Factor)**
- **出场原因分布 (TP/SL/TL)**
- **策略切换次数** (固定策略恒为 0)

## 六、代码实现说明

### 核心文件

| 文件 | 说明 |
|------|------|
| `scripts/fixed_strategy_backtest.py` | 主回测脚本，包含策略信号函数、回测引擎、网格搜索、汇总输出 |

- Python 3.12
- pandas + numpy（数据处理）
- pandas_ta（技术指标计算）

```bash
cd <project_root>
pip install pandas numpy pandas_ta
```
