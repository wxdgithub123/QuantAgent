⚠️ 已知局限与注意事项

⚠️ AI 决策速度

TradingAgents 每次调用会触发 4-11 次 LLM 请求（并行分析 + 多空辩论 + 风控辩论）。 使用 DeepSeek API 时，fast 模式约 30-60 秒，完整模式约 2-4 分钟。 这不是 bug，是 LLM 推理固有的延迟。

⚠️ Binance API Key 未配置

网关使用 Binance Testnet 拉取公开行情，但无法执行真实下单。 如需测试交易功能，需在 .env 中填入 BINANCE_API_KEY 和 BINANCE_SECRET_KEY。

⚠️ Paper Bot 需 Docker 网络

Hummingbot Paper Bot 创建和启动需要 Docker 能拉取镜像，当前 Docker 网络受限， 可能无法创建新的 Bot 容器。已有的 Bot 容器是之前缓存的。
